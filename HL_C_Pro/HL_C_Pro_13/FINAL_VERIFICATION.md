## 🎬 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Создание фильма с файлом
```
1. На Index: Нажать "Добавить новый фильм"
2. На Create: Заполнить Name, Genre, Year
3. На Create: Выбрать файл MP4 (без URL)
4. На Create: Нажать "Сохранить"
5. Результат: Фильм добавлен, плеер работает ✅
```

### Создание фильма с URL
```
1. На Index: Нажать "Добавить новый фильм"
2. На Create: Заполнить Name, Genre, Year
3. На Create: Ввести URL (без файла)
4. На Create: Нажать "Сохранить"
5. Результат: Фильм добавлен, плеер работает ✅
```

### Создание фильма БЕЗ файла и URL
```
1. На Index: Нажать "Добавить новый фильм"
2. На Create: Заполнить Name, Genre, Year
3. На Create: НЕ выбирать файл, НЕ вводить URL
4. На Create: Нажать "Сохранить"
5. Результат: Фильм добавлен (без медиа) ✅
```

### Редактирование с заменой файла
```
1. На Index: Нажать "Редактировать"
2. На Edit: Загрузить новый файл
3. На Edit: Нажать "Обновить"
4. Результат: Старый файл удален, новый сохранен ✅
```
