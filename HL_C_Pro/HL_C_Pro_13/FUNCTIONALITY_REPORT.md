## 📁 Структура проекту

### Моделі
- ✅ `Models/Movie.cs` - Модель фільму з валідацією
  - `Id` (int) - Унікальний ідентифікатор
  - `Title` (string) - **Обов'язкове** - Назва фільму
  - `Genre` (string) - **Обов'язкове** - Жанр
  - `Year` (int) - **Обов'язкове** - Рік випуску (1888-2100)
  - `MovieFilePath` (string?) - **Опціональне** - Шлях до завантаженого файлу
  - `MovieUrl` (string?) - **Опціональне** - Посилання на зовнішній файл

### Сервіси
- ✅ `Services/IMovieService.cs` (MovieService) - Управління даними
  - Використовує `static readonly List<Movie>` для збереження даних в рамках сеансу
  - Методи: `GetAll()`, `Add()`, `GetById()`, `Update()`, `Delete()`
  - 6 початкових фільмів для тестування

### Контролери
- ✅ `Controllers/MoviesController.cs` - Управління фільмами
  - **Index** (GET) - Список всіх фільмів з фільтрацією
  - **Details** (GET) - Перегляд конкретного фільму
  - **Create** (GET/POST) - Додавання нового фільму
  - **Edit** (GET/POST) - Редагування існуючого фільму
  - **Delete** (GET) - Видалення фільму

### Представлення (Views)
- ✅ `Views/Movies/Index.cshtml` - Список фільмів з фільтрацією
- ✅ `Views/Movies/Details.cshtml` - Деталі та програвач
- ✅ `Views/Movies/Create.cshtml` - Форма для додавання
- ✅ `Views/Movies/Edit.cshtml` - Форма для редагування
- ✅ `Views/Home/Index.cshtml` - Головна сторінка
- ✅ `Views/Shared/_Layout.cshtml` - Макет додатка

### 2️⃣ ДОДАВАННЯ ФІЛЬМУ (Create)
**Функція**: Додавання нового фільму до каталогу

**Обов'язкові поля**:
- ✅ **Назва фільму** (Title) - текстове поле
- ✅ **Жанр** (Genre) - текстове поле
- ✅ **Рік випуску** (Year) - числове поле (1888-2100)

**Опціональні поля**:
- ✅ **Варіант 1: Завантажити файл** - file input (MP4, WebM, AVI, MKV, MOV)
- ✅ **Варіант 2: Посилання на фільм** - text input для URL

**Логіка валідації**:
- ✅ Назва обов'язкова - вимагається
- ✅ Жанр обов'язковий - вимагається
- ✅ Рік обов'язковий - від 1888 до 2100
- ✅ Файл та посилання - **ОПЦІОНАЛЬНІ** (можна додати фільм без них)
- ✅ Якщо завантажено файл → очищується URL поле
- ✅ Якщо введено URL → залишається тільки URL (без файлу)

**Обробка файлів**:
- ✅ Файли зберігаються у `wwwroot/movies/`
- ✅ Використовується UUID для унікальної назви файлу
- ✅ Директорія автоматично створюється, якщо не існує

**Перенаправлення**:
- ✅ Після успішного додавання → перенаправлення на Index

**Статус**: ✅ **ГОТОВО**
