## 💾 ТИПОВІ СЦЕНАРІЇ ВИКОРИСТАННЯ

### Сценарій 1: Додавання фільму з файлом
```
1. Нажмите "Додати новий фільм"
2. Заповніть: Назва, Жанр, Рік
3. Виберіть MP4 файл
4. Нажмите "Зберегти"
✅ Фільм додан, можна переглядати!
```

### Сценарій 2: Додавання фільму з URL
```
1. Нажмите "Додати новий фільм"
2. Заповніть: Назва, Жанр, Рік
3. Введіть URL посилання
4. Нажмите "Зберегти"
✅ Фільм додан, посилання активне!
```

### Сценарій 3: Додавання фільму БЕЗ файлу та URL
```
1. Нажмите "Додати новий фільм"
2. Заповніть: Назва, Жанр, Рік
3. НЕ вибирайте файл, НЕ вводьте URL
4. Нажмите "Зберегти"
✅ Фільм додан без медіа-файлу!
```

### Сценарій 4: Поіск та фільтрація
```
1. На Index введіть текст пошуку
2. Виберіть чекбокси жанрів та років
3. Нажмите "Шукати"
✅ Результати відповідають критеріям!
```
