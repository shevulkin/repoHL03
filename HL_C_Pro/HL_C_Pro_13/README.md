Створити веб-додаток для управління каталогом фільмів з наступним функціоналом:

✅ Перегляд списку фільмів з фільтрацією

✅ Захист від скачування відео  
✅ Підтримка як завантаженого файлу, так і URL посилання

## 🚀 ФУНКЦІОНАЛЬНІСТЬ

### 1. Індексна сторінка (Список фільмів)
- **Маршрут**: `GET /Movies`
- **Можливості**:
  - 📺 Таблиця всіх фільмів
  - 🔍 Пошук за назвою (підстрока)
  - 🎬 Фільтр за жанром (мультиселект)
  - 📅 Фільтр за роком (мультиселект)
  - ➕ Додавання нового фільму
  - ✏️ Редагування
  - 🗑️ Видалення (з підтвердженням)
  - 👁️ Перегляд деталей

### 2. Додавання фільму (Create)
- **Маршрут**: `GET/POST /Movies/Create`
- **Обов'язкові поля**:
  - Назва фільму
  - Жанр
  - Рік випуску (1888-2100)
- **Опціональні поля**:
  - Завантажити файл (MP4, WebM, AVI, MKV, MOV)
  - Посилання на фільм (URL)
- **Обробка**:
  - UUID для унікальних імен файлів
  - Збереження в `wwwroot/movies/`
  - Автоматична генерація ID

### 3. Редагування фільму (Edit)
- **Маршрут**: `GET/POST /Movies/Edit/{id}`
- **Можливості**:
  - Редагування всіх полів
  - Заміна файлу (видалення старого)
  - Заміна URL (видалення файлу)
  - Збереження без змін медіа
  - Показання поточного медіа

### 4. Перегляд фільму (Details)
- **Маршрут**: `GET /Movies/Details/{id}`
- **Можливості**:
  - 📹 HTML5 програвач видео
  - 🎚️ Контролічки play/pause/звук/шкала часу
  - 🚫 Запобігання скачуванню (controlsList="nodownload")
  - 📱 Адаптивний розмір
  - ✏️ Посилання на редагування

### 5. Видалення фільму (Delete)
- **Маршрут**: `GET /Movies/Delete/{id}`
- **Можливості**:
  - 🔒 Підтвердження у діалозі
  - 🗑️ Видалення файлу з диска
  - 📋 Видалення запису з бази даних

## 💾 ДАНІ

### Модель Movie
```csharp
public class Movie
{
    public int Id { get; set; }                    // Унікальний ID
    public string Title { get; set; }              // [Required]
    public string Genre { get; set; }              // [Required]
    public int Year { get; set; }                  // [Range(1888, 2100)]
    public string? MovieFilePath { get; set; }     // Опціонально
    public string? MovieUrl { get; set; }          // Опціонально
}
```

### Сховище даних
- **Тип**: Static List<Movie> (в пам'яті)
- **Персистентність**: Протягом сеансу додатка
- **Початкові дані**: 6 фільмів
  - Інтерстеллар (2014, Sci-Fi)
  - Хрещений батько (1972, Drama)
  - Матриця (1999, Sci-Fi)
  - Форест Гамп (1994, Drama)
  - Темний лицар (2008, Action)
  - Король лев (1994, Animation)
