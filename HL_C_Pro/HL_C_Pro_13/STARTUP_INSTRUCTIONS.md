## 🎬 Тестування функціональності

Після запуску додатка (https://localhost:7125), протестуйте:

### ✅ Тест 1: Переглянути список фільмів
```
Дія: Клацнути "🎬 Перейти до каталогу фільмів"
Очікування: Таблиця з 6 фільмів
```

### ✅ Тест 2: Додати фільм з файлом
```
Дія: 
1. Клацнути "Додати новий фільм"
2. Заповнити Назва, Жанр, Рік
3. Вибрати файл MP4
4. Клацнути "Зберегти"
Очікування: Фільм додано, вернення на Index
```

### ✅ Тест 3: Додати фільм з URL
```
Дія:
1. Клацнути "Додати новий фільм"
2. Заповнити Назва, Жанр, Рік
3. Ввести URL посилання
4. Клацнути "Зберегти"
Очікування: Фільм додано, вернення на Index
```

### ✅ Тест 4: Додати фільм БЕЗ файлу та URL
```
Дія:
1. Клацнути "Додати новий фільм"
2. Заповнити Назва, Жанр, Рік
3. НЕ вибирати файл, НЕ вводити URL
4. Клацнути "Зберегти"
Очікування: Фільм додано (файл та URL опціональні!)
```

### ✅ Тест 5: Перегляд з програвачем
```
Дія: Клацнути на назву фільму (що має файл або URL)
Очікування: 
- HTML5 відеопрогравач
- Контролічка play/pause/звук/шкала часу
- НЕМАЄ кнопки скачування
```

### ✅ Тест 6: Редагування фільму
```
Дія:
1. Клацнути "Редагувати"
2. Змінити якесь поле
3. Клацнути "Оновити"
Очікування: Фільм оновлений, вернення на Index
```

### ✅ Тест 7: Видалення фільму
```
Дія:
1. Клацнути "Видалити"
2. Підтвердити у діалозі
Очікування: Фільм видалений, вернення на Index
```

### ✅ Тест 8: Пошук та фільтрація
```
Дія:
1. Ввести текст пошуку (наприклад "матр")
2. Вибрати чекбокси жанрів/років
3. Клацнути "Шукати"
Очікування: Результати відповідають критеріям
```

## 🐛 Розв'язання проблем

### Проблема: Портал HTTPS не запускається
**Рішення**:
```powershell
# Довірити сертифікату розробки
dotnet dev-certs https --trust
```

### Проблема: Порт 7125 вже використовується
**Рішення**: Змінити порт у launchSettings.json
```json
"applicationUrl": "https://localhost:7126"
```

### Проблема: Файли не завантажуються
**Перевірка**:
- Директорія `wwwroot/movies/` існує? (створіється автоматично)
- Дозволи на запис в `wwwroot/`?
- Розширення файлу підтримується? (.mp4, .webm, .avi, .mkv, .mov)

### Проблема: Дані теряються при перезагрузці
**Це нормально!** Додаток використовує в-пам'яті сховище (static List).
Дані зберігаються тільки під час однієї сесії.

```
│   ├── MoviesController.cs      ← Головний контролер

│   ├── Movies\

│   │   ├── Create.cshtml        ← Форма додавання
│   │   ├── Edit.cshtml          ← Форма редагування
│   │   └── Details.cshtml       ← Перегляд + програвач
│   ├── Home\
│   │   └── Index.cshtml         ← Головна сторінка
│   └── Shared\
│       └── _Layout.cshtml       ← Макет сторінок
├── wwwroot\
│   ├── movies\                  ← Завантажені файли
│   ├── lib\                     ← Bootstrap, jQuery
│   └── css\
├── Program.cs                   ← Конфігурація додатка
└── HL_C_Pro_13.csproj          ← Файл проекту
```
